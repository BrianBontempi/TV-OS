# TV-OS

My personal tv os: una Home in stile Apple per la mia Sony BRAVIA (Android TV 12).

## Stato

Fase 1, versione di prova: elenca gli ingressi HDMI con i nomi delle console, registra i tasti del telecomando e le schermate aperte, prova a sostituire il tasto HOME.

## Installazione sulla TV

1. Ogni modifica su `main` viene compilata da GitHub Actions.
2. Il file da installare è sempre allo stesso indirizzo:
   `https://github.com/BrianBontempi/TV-OS/releases/download/ultima/tv-home.apk`
3. Sulla TV: app Downloader, inserisci l'indirizzo, Installa.
